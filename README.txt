FUNNGRO WEBSITE REVAMP — CONCEPT SUBMISSION

Files:
- index.html: Teen-facing landing page
- company.html: Company-facing landing page
- styles.css: Responsive styles
- script.js: Mobile navigation interaction
- SEO_Audit_Report.pdf: Initial SEO review and recommendations

Preview:
Open index.html in a browser. Use the “For Companies” link to switch pages.

Deployment:
Upload the files to a static host (GitHub Pages, Netlify, or Vercel). For GitHub Pages, upload all files to a repository and enable Pages from the repository settings.

Important:
This is an independent concept redesign for a project challenge, not an official Funngro website. The canonical tags in the sample HTML point to the corresponding official URL paths as placeholders; update them to the actual deployed preview URLs before public deployment. The SEO report is a desk-based review of publicly visible pages, not a server-side technical crawl.
